🎮 Abstract Warfare Tower Defense

A minimalist tower defense game featuring geometric shapes and smooth animations.

🎯 Play Game 📖 Documentation

✨ Key Features

🎯 Strategic Gameplay

Place hexagonal towers strategically on a 10x10 grid to defend against waves of geometric enemies.

🔴 Multiple Enemy Types

Face circles (basic), triangles (fast), and squares (tank) with different health and speed values.

⚡ Smooth Animations

60 FPS gameplay with death animations, projectile trails, and visual feedback effects.

🎨 Minimalist Design

Clean geometric aesthetic with color-coded enemies and intuitive UI design.

🚀 How to Play

  1. Place Towers: Click on gray tiles to place hexagonal towers (max 5)
  2. Start Wave: Click "Start Wave" when ready to begin the attack
  3. Defend: Watch your towers automatically target and destroy enemies
  4. Survive: Prevent enemies from reaching the end of the path
  5. Progress: Complete waves to advance to higher difficulties

🛠️ Technical Details

  • Pure JavaScript: No external dependencies, runs entirely in the browser
  • HTML5 Canvas: Hardware-accelerated rendering for smooth performance
  • Modular Architecture: Clean separation of concerns with separate classes
  • Responsive Design: Works on different screen sizes and devices
